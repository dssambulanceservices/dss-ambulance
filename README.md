## 🚑 Services Offered

1. **Normal Ambulance Service** – Routine patient transportation, hospital visits, appointments, and diagnostic checkups.
2. **Ventilator Ambulance Service** – Critical care transport equipped with hospital-grade portable ventilators, multiparameter monitors, oxygen, and trained paramedics.
3. **Mortuary Ambulance Service** – Dignified, solemn, and respectful transport of deceased persons (freezer box available upon request).
4. **Hospital Transfer** – Transit between hospitals, clinics, and diagnostic centers across Delhi NCR.
5. **Inter-Hospital Transfer** – Coordinated transfer to advanced multi-specialty healthcare facilities.
6. **Local Ambulance Service** – Prompt ambulance coverage across all sectors of Delhi NCR.
7. **Outstation Ambulance Service** – Long-distance medical journeys connecting Delhi NCR to UP, Haryana, Rajasthan, Punjab, Uttarakhand, and beyond.
8. **Patient Transportation** – Comfortable bed-to-bed travel support.
9. **Patient & Attendant Support** – Reassuring care and spacious cabin seating for accompanying family members.
10. **Ambulance Booking Assistance** – 24/7 dispatch coordination.

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/imamitdev/dss-ambulance.git
   cd dss-ambulance
   ```
2. Open `index.html` in any web browser, or serve with Python:
   ```bash
   python -m http.server 3000
   ```
3. Visit `http://localhost:3000` in your browser.
